Como funciona
Com URL de Login configurada (JWT/OAuth2):
Preencha Usuário e Senha → clique Salvar → o sistema conecta automaticamente e captura o token.

Bearer Token Estático:
Cole o token diretamente no campo "Token Estático". O sistema vai injetá-lo em todas as requisições.

Campos em branco = sem alteração.
Segurança
Usuário, Senha e Token são gravados com criptografia AES-256.
Nunca aparecem no HTML, nos logs ou no banco em texto puro.
